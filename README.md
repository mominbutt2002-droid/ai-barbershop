# Кромка

Барбершоп в Казани: лендинг, запись на кресло, админка смен и Telegram-бот. Сайт и бот пишут в одну базу SQLite.

Стек: JavaScript, Next.js, React, Prisma, grammY.

## Запуск

```bash
npm install
npm run db:setup
npm run dev
```

Сайт откроется на http://localhost:3000.

Вход в админку: http://localhost:3000/admin/login, пароль из `ADMIN_PASSWORD`. В примере это `kromka`.

`npm run db:setup` заново записывает мокап: 4 мастера, 6 услуг и заявки на ближайшие рабочие дни. Старые заявки при этом стираются.

## Что есть на сайте

- Лендинг со сменой на сегодня, прайсом и мастерами.
- Запись: услуга, мастер или «любой свободный», календарь, время, имя и телефон.
- Админка: загрузка кресел на день, график мастеров, список заявок.
- Переключатель светлой и тёмной темы в шапке.

## Telegram

1. В BotFather выполните `/newbot` и вставьте токен в `BOT_TOKEN` файла `.env`.
2. Создайте группу и добавьте туда бота.
3. Узнайте id группы. Напишите в группу любое сообщение и откройте в браузере `https://api.telegram.org/bot<токен>/getUpdates`. Id выглядит как `-100...`. Вставьте его в `GROUP_CHAT_ID`.
4. Запустите бота во втором терминале: `npm run bot`. Бот: [@BRB01_bot](https://t.me/BRB01_bot). В личке нажмите «Календарь» (Mini App) или «Записаться в чате».

### Mini App (календарь в Telegram)

Страница приложения: `/mini`. Telegram открывает только HTTPS.

Пока проект локальный:

1. `npm run dev`
2. В третьем терминале `npm run tunnel` — появится адрес `https://….trycloudflare.com`
3. В `.env` укажите `WEBAPP_URL=https://….trycloudflare.com`
4. Перезапустите `npm run bot`

После публикации сайта на домене с HTTPS достаточно прописать тот же адрес в `WEBAPP_URL` (можно с путём `/mini` или без — бот сам откроет `/mini`) и снова запустить бота. Кнопка меню «Календарь» выставится сама.

Запись из личного чата с ботом попадает в ту же базу, что и запись с сайта. Новая заявка дублируется в группу. Сообщение в группу отправляет сам сайт, даже если процесс бота не запущен. Если токен или id группы пустые, заявка всё равно сохраняется, а в консоли будет строка, что уведомление не ушло.

Клиенту, который писал боту, за час и за пять минут до визита уходит напоминание в личные сообщения. Тот же текст можно отправить кнопкой «Напомнить в Telegram» в админке (смена и список заявок). Напоминания идут, пока запущен сайт (`npm run dev`) или бот (`npm run bot`) и задан `BOT_TOKEN`. Запись с сайта получит чат, если этот телефон уже был в заявке из Telegram.

Команды бота: `/start` начать запись, `/cancel` остановить.

Скопируйте `.env.example` в `.env`, если файла окружения ещё нет. Часовой пояс салона: `Europe/Moscow`.
